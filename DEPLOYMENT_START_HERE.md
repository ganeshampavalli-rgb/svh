## The Three Simplest Steps

### Step 1: Push Code to GitHub (5 min)
```powershell
cd C:\Users\GaneshAmpavalli\Ganesh_Workspace\SVH
git config --global user.name "Your Name"
git config --global user.email "your.email@gmail.com"
git add .
git commit -m "Deploy"
git remote add origin https://github.com/YOUR_USERNAME/SVH.git
git branch -M main
git push -u origin main
```

### Step 2: Deploy on Vercel (5 min)
1. Go to https://vercel.com
2. Click "Sign up with GitHub"
3. Click "New Project"
4. Select "SVH"
5. Set Root Directory to "frontend"
6. Click "Deploy"

### Step 3: Wait & Access (3 min)
Wait for build to complete, then:
```
https://svh-frontend.vercel.app
```

**DONE!** 🎉
