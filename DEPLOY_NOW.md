### STEP 2: Push Your Code to GitHub (5 minutes)

Open PowerShell and copy-paste each command:

```powershell
cd C:\Users\GaneshAmpavalli\Ganesh_Workspace\SVH
```

```powershell
git config --global user.name "Your Full Name"
```

```powershell
git config --global user.email "your.email@gmail.com"
```

```powershell
git add .
```

```powershell
git commit -m "Deploy SVH frontend and backend"
```

Now create a repository:
1. Go to: https://github.com/new
2. Repository name: `SVH`
3. Click "Create repository"
4. Copy the URL shown

Back in PowerShell, replace `YOUR_USERNAME` and run:

```powershell
git remote add origin https://github.com/YOUR_USERNAME/SVH.git
```

```powershell
git branch -M main
```

```powershell
git push -u origin main
```

✅ **Your code is now on GitHub!**

---

### STEP 3: Deploy to Vercel (5 minutes)

1. Go to: **https://vercel.com**
2. Click **"Sign Up"**
3. Click **"GitHub"**
4. Click **"Authorize Vercel"**
5. You're logged in!

Now deploy:
1. Click **"New Project"**
2. Find and select **"SVH"** repository
3. Click **"Import"**

Configure settings:
- Root Directory: Click dropdown, select **`frontend`**
- Keep other settings as default
- Click **"Deploy"**

✅ **Vercel is building your app!**

---

### STEP 4: Wait for Build (3 minutes)

Just wait! You'll see "Building..." on the screen.

When it says "Deployment Complete", you're done! 🎉

---

### STEP 5: Get Your Live URL (Instant)

Click the big URL button:

```
https://svh-frontend.vercel.app
```

**This is your PUBLIC app!** 🌍

Open it in browser to see your app LIVE!
